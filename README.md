# 🎓 Student Registration & Result Portal

A responsive and interactive **Student Registration & Result Portal** developed as an academic mini project using **HTML5, CSS3, Bootstrap 5, and JavaScript**.

The application allows students to enter their personal details, select a course, enter subject marks, calculate total marks and percentage, and display their final result through a simple, responsive, and user-friendly interface.

---

## 📌 Project Overview

The **Student Registration & Result Portal** is a frontend web development mini project created to demonstrate the practical integration of **HTML5, CSS3, Bootstrap 5, and JavaScript**.

The project provides a structured portal where students can register their details and calculate their academic results.

### The portal allows students to:

- Enter personal details
- Enter registration number
- Enter contact information
- Select a course
- Enter subject marks
- Calculate total marks
- Calculate percentage
- Determine result status
- View the final result
- Use the portal on different screen sizes

## 🔄 Application Workflow

1. Open the Student Registration & Result Portal.
2. Enter the student's personal information.
3. Enter the registration number and contact details.
4. Select the required course.
5. Enter marks for the required subjects.
6. Submit the form.
7. JavaScript validates the entered information.
8. Total marks are calculated.
9. Percentage is calculated.
10. Result status is determined.
11. The final result is displayed to the user.

## 🧮 Result Calculation

### Total Marks

The total marks are calculated by adding the marks obtained in all subjects.

**Formula:**

Total Marks = Subject 1 + Subject 2 + Subject 3 + Subject 4 + Subject 5

### Percentage

The percentage is calculated using the following formula:

Percentage = (Total Marks / Maximum Marks) × 100

The calculated total and percentage are displayed dynamically in the result section.
